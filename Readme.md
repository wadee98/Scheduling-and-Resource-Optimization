# System Scheduling & Resource Optimization Suite

This repository contains a collection of advanced projects focused on **resource management**, **process scheduling**, and **data validation**. By leveraging different programming paradigms—Object-Oriented Java, Scripting in Python, and Automation in Bash—this suite demonstrates a comprehensive approach to solving scheduling constraints.

## 🚀 Projects Overview

### 1. [CPU Scheduler & Deadlock Simulator](./CPU-Deadlock-Simulator) (Java)
An Operating Systems simulation that manages process lifecycles and resource safety.
* **Core Logic:** Implements Bankers-style deadlock detection and recovery.
* **Scheduling:** Simulates CPU/IO bursts with customizable priorities.

### 2. [Multi-Instructor Policy Engine](./Instructor-Schedule-Validator) (Python)
An enterprise-grade validation system for academic course loads.
* **Architecture:** Full Object-Oriented design with a configurable policy engine.
* **Features:** Regex-based data extraction and detailed instructor performance reporting.

### 3. [Schedule Integrity Utility](./Bash-Schedule-Analyzer) (Shell)
A lightweight Linux automation tool for rapid schedule auditing.
* **Functionality:** Uses `grep`, `awk`, and `sed` to verify day-group compliance and workload distribution.
